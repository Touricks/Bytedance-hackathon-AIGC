# Rules
1. viralTemplateUsed: write the full template name (e.g. 美妆/护肤 · 痛点蜕变型).
2. matchReason: one sentence explaining why this template fits the product and audience.
3. voiceover ≤ 15 Chinese characters. Match the tone described in the template's emotional arc.
4. scene ≤ 20 characters. Format: [location] + [lighting].
5. productAssetRef must be one of the provided materialRefs.
6. The emotional arc of all 6 shots must follow the selected template's arc — not the default angleType arc.
7. Do not mix techniques from multiple templates.
