# User Journey

本文由产品视角描述用户如何完成一次 AIGC 视频生成。接口只是支撑手段，正文优先写用户动作和系统反馈。

## 旅程草稿

```text
用户创建会话
  -> 选择工作文件夹
  -> 上传商品素材
  -> 用户确认商品简介
  -> 用户确认总体剧本
  -> 系统生成分镜剧本
  -> 用户逐镜头生成并选择图片
  -> 用户逐镜头生成并选择视频
  -> 用户合成最终视频
  -> 用户预览或下载成片
  -> 用户选择kol渠道发布视频（平台 + 签约经纪人）
  -> 用户查看在特定kol渠道发布的特定视频的曝光率/点击率
```

#### 新建会话

业务目的：
用户开启一个会话，系统需要通过 workspaceId 找到本地工作目录。

触发时机：
- 用户从历史项目列表点击进入项目
- 前端恢复项目上下文
- 调试时定位本地素材目录

接口：
GET /api/workspaces/:workspaceId/directory

成功结果：
系统返回该 workspace 的本地目录。

失败情况：
| 场景 | 系统行为 | 建议用户提示 |
|---|---|---|
| workspaceId 不存在 | 返回 404 | 项目不存在或已被清理 |
| 服务异常 | 返回 500/400 | 项目路径查询失败，请稍后重试 |

产品注意：
该接口返回本机绝对路径，属于本地环境信息，不应展示给普通终端用户。
