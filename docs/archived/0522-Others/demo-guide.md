# Demo Guide

## Goal

Show the P0 path:

```text
product image + selling points
-> structured script
-> storyboard shots
-> one 12 second final video
-> preview/export
```

## Before Presentation

1. Replace `MOCK_FINAL_VIDEO_URL` with a real pre-generated video if available.
2. Put 1-2 final videos under `mocks/videos/`.
3. Keep `docs/archive/prd.pdf` and all six architecture files for review.
4. Confirm the public demo URL opens without login or with a shared demo account.

## Fallback

If real-time generation is slow or fails, use the pre-generated sample video. The code path still demonstrates job creation, structured script generation, storyboard display and preview.
