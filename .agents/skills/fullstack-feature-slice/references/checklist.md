# Full-stack feature checklist

Use this as a review checklist after implementation.

- [ ] Source of truth identified.
- [ ] UI does not duplicate backend business rules.
- [ ] API/schema contract is updated intentionally.
- [ ] Tests cover old and new behavior where compatibility matters.
- [ ] Data migrations include rollback/remediation notes.
- [ ] Security-sensitive paths have negative tests.
- [ ] Targeted verification commands were run and recorded.
- [ ] Unrelated cleanup was avoided or split out.
